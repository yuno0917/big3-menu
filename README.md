# BIG3 メニューメーカー

スクワット・ベンチプレス・デッドリフトの MAX を入れるだけで、初心者〜中級者向けの 8 週間トレーニングメニューを自動で作る Web ツールです。

- 毎回の重量・セット数・RPE の目安・片側のプレートを表示
- MAX がわからない場合は「重量 × 回数」から推定
- 週 2〜4 回、2.5kg / 5kg 刻み、オーバーヘッドプレスの追加に対応
- 入力はブラウザ内だけで計算し、サーバーには送信しない

## ローカルで動かす

ビルドは不要です。`index.html` をブラウザで開くだけで動きます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 入力フォーム・結果・解説・免責 |
| `privacy.html` | プライバシーポリシー |
| `tests.html` | ロジックのテスト（ブラウザで開くと結果を表示） |
| `css/style.css` | 見た目（ライト / ダーク / 印刷） |
| `js/program-data.js` | 週ごとの % やセット数、補助種目などの設定値 |
| `js/program.js` | メニュー生成ロジック |
| `js/plates.js` | 重量の丸めとプレート計算 |
| `js/onerm.js` | 推定 1RM（Epley の式） |
| `js/app.js` | フォーム・描画・保存・共有リンク |

## メニューを調整する

重量の割合・セット数・補助種目は `js/program-data.js` にまとまっています。書き換えたら `tests.html` を開き、テストがすべて通ることを確認してください。
